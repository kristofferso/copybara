How it works Install GitHub

Edit your copy right where it is.

Copybara lets anyone review the text on your website by clicking it. Rewrites and notes land in one structured list, ready for your coding agent. No more spreadsheets, screenshots and Slack threads.

add copybara

Copy feedback without the back-and-forth.

Today

  • Screenshots with red circles on them
  • A spreadsheet with “old text” and “new text” columns
  • Slack threads about “the second button on the pricing page”
  • A developer hunting down every string by hand

With Copybara

  • Click the text and type the new version
  • Notes pinned to the exact element they are about
  • One structured list of changes per page
  • A prompt your agent can act on right away

1 Edit

Turn Copybara on and click a heading, a button or a paragraph. Type the new text and press Enter.

2 Comment

Switch to Comment to flag an image, a section or a sentence you want someone else to look at.

3 Hand off

Copy everything as one prompt for Claude Code, Cursor or any agent. It says what to change and where to look.

Try it on this page.

Turn Copybara on with the button in the corner and change anything you like, this sentence included. The prompt below updates as you go, and nothing leaves your browser.

Install in a minute.

        
No dependencies, about 15 kB gzipped.


        

          

            
            
            
          

          

            

              

                
                
                
                
              

              

                $ bun add copybara
                
              

            

            
// app/layout.tsx
import { Copybara } from 'copybara/react'

<Copybara enabled={process.env.NODE_ENV !== 'production'} />

            
The core is loaded only when enabled is true, so production visitors never download it.

          

          

            
<script
  src="https://cdn.jsdelivr.net/npm/copybara/dist/copybara.global.js"
  data-position="bottom-right"
></script>

            
Works on any site. Set window.copybaraConfig before the tag for the full config.

Tell the agent about your codebase

            
Say where copy lives and how your team writes. The prompt gets sharper and the agent stops guessing.

          

          

            
<Copybara
  instructions="Use sentence case."
  codebase={{
    framework: 'Next.js with next-intl',
    textSources: ['messages/{locale}.json'],
    notes: 'Marketing copy lives in Sanity.',
  }}
/>

          

        


        

          
            
OptionDefaultDescription

          
          
            
enabledtrueRender nothing when false.

            
position'bottom-left'Or 'bottom-right'.

            
theme'auto'Or 'light' and 'dark'.

            
instructionsExtra instructions added to the prompt.

            
codebaseframework, textSources and notes.

            
ignoreSelector for elements to leave alone. data-copybara-ignore always works.

            
storageKey'copybara'localStorage key for saved changes.
